# Input data

Place your locally held `EXGRVA_Joint_Matrix_Long_1995_2022.csv.gz` in this folder.
The full data file is intentionally NOT included in the public repository.

The prepared long matrix was derived from OECD TiVA 2025 edition, January 2026 revision, EXGRVA indicator. The code accepts the eight-column prepared format documented in the root README. It does **not** implement the earlier OECD download, category mapping, or reconciliation stages.

Verify relevant OECD data licence and redistribution requirements before sharing upstream data.
